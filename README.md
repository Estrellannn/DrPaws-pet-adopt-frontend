# DrPaws宠物领养网站 - 前端
基于springboot+vue开发的前后端分离宠物领养网站项目，后端项目在：https://github.com/Estrellannn/DrPaws-pet-adopt-backend

## 技术栈
Vue3 + Vite、
Element Plus UI组件库、
Bootstrap、
Vue Router 路由管理、
CSS 页面样式开发、
JavaScript、

## 功能说明
1.页面导航路由跳转。
2.宠物领养展示和类型筛选。
3.帖子展示和类型筛选。
4.详情弹窗预览。
5.用户的登录。

## 环境依赖
- Node.js : 16+
- 包管理器：Yarn
- 框架：Vue3 + Vite

## 启动说明 
安装依赖 ：npm install  
启动本地开发服务器 ：npm run dev
输入网址:http://localhost:5173 进入网址
