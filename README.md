# DrPaws宠物领养网站
基于 Vue3 + Vite + ElementPlus 开发的宠物领养平台前端项目

##技术栈
Vue3 + Vite
Element Plus UI组件库
Bootstrap
Vue Router 路由管理
CSS 页面样式开发
JavaScript

##功能说明
1.页面导航路由跳转。
2.宠物领养展示和类型筛选。
3.帖子展示和类型帅选
4.详情弹窗预览。

##启动说明
环境要求 : Node.js 版本建议 >=16  
安装依赖 ：npm install  
启动本地开发服务器 ：npm run dev
